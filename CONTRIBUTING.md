# Contributing

This repository is an internship challenge submission. Contributions are welcome as issues or pull requests that improve clarity, reproducibility, or research quality.

## Guidelines

1. Keep the **personal-data constraint** intact: approaches must use data collected for this project.
2. Prefer small, reviewable PRs with a clear motivation.
3. Do not commit secrets, large raw videos, or third-party books that forbid redistribution.
4. Document design choices and failed experiments in the README or `docs/`.
5. Match existing code style; add a short note if you introduce a new dependency.

## Development setup

See the root `README.md` once the pipeline is implemented. Research pointers live under `resources/`.
